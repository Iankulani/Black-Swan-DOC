Installation step-by-step

Get BLACK_SWAN_V4 running in minutes. Python 3.7+ required.

quick install pip install -r requirements.txt
1
Clone repository
git clone https://github.com/Iankulani/black_swan.git
cd black_swan
2
Create virtual environment (recommended)
python3 -m venv venv
source venv/bin/activate (Linux/mac) · venv\Scripts\activate (Windows)
3
Install core dependencies
pip install -r requirements.txt
includes: requests, psutil, cryptography, flask, socketio, scapy, paramiko, pynput, discord.py, telethon, slack-sdk, etc.

(Optional) Install system tools
sudo apt install nmap nikto whois dnsutils netcat-openbsd docker.io

Launch BLACK_SWAN_V4
python black_swan.py

Web dashboard (optional)
